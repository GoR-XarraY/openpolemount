**An open-source, 3D-printable IV pole cradle for the Curlin CMS6000 infusion pump — and the foundation for an open accessory ecosystem for home IV poles.**

> **This is not a business — it's an open-source medical hardware project.** Every file is free. The goal is that anyone who needs a cradle can print one themselves. A print-on-demand option exists only so people without a printer aren't left out, at cost.

> ⚠️ **REFERENCE DESIGN — NOT A MEDICAL DEVICE.** These files are provided for informational and educational purposes. See [DISCLAIMER.md](DISCLAIMER.md) before use.

---

## The Problem

Curlin CMS6000 IV pole mounting cradles are backordered. The bag alternative
sent by pharmacies can only be used properly by a few experienced nurses.
Many home-healthcare patients need a reliable, easy-to-use mounting solution now.

## The Solution — IV Pole Cradle v3

An open-source cradle that any maker can print and any patient can assemble.
**v3 is the current, recommended design**: a smaller, more form-fitting redesign
of v2, built from user feedback and shaped specifically for the Curlin CMS6000.
The pump seats snugly with the keypad accessible, and a printed T-handle
thumbscrew clamps it to a standard home IV pole. The mounting section is the
**OpenPoleMount block** — a universal standard for any accessory on a home IV pole.

> **v2** is still fully released and print-ready — it's now documented as a
> **universal device holder** (may fit several infusion pumps or other devices;
> no confirmed compatibility list yet). It's also the version currently available
> via print-on-demand order.

> The original **v1** is not very functional as a pump cradle and is best
> repurposed as an accessory box that mounts below the pump.

> **Note:** v3's print files are still being finalized for release — see
> [openpolemount.com/iv-pole-v3](https://openpolemount.com/iv-pole-v3/) for status.

## Quick Start

1. **Download** the STL files from [Releases](https://github.com/GoR-XarraY/openpolemount/releases/latest)
2. **Print** the v3 cradle in PLA once released — see the [v3 Print Guide](https://openpolemount.com/iv-pole-v3/print-settings/); the [v2 Print Guide](https://openpolemount.com/iv-pole-v2/print-settings/) is available today
3. **Assemble** — see the [v3 Assembly Guide](https://openpolemount.com/iv-pole-v3/assembly/)
4. **Read the disclaimer** — [DISCLAIMER.md](DISCLAIMER.md)

No printer? v2 can be printed on demand and shipped at cost via Slant 3D / Teleport — see [openpolemount.com](https://openpolemount.com/order/). (v3 print-on-demand isn't set up yet.)
