**An open-source, 3D-printable IV pole cradle for the Curlin CMS6000 infusion pump — and the foundation for an open accessory ecosystem for home IV poles.**

> **This is not a business — it's an open-source medical hardware project.** Every file is free. The goal is that anyone who needs a cradle can print one themselves. A print-on-demand option exists only so people without a printer aren't left out, at cost.

> ⚠️ **REFERENCE DESIGN — NOT A MEDICAL DEVICE.** These files are provided for informational and educational purposes. See [DISCLAIMER.md](DISCLAIMER.md) before use.

## The Problem

Curlin CMS6000 IV pole mounting cradles are backordered. The bag alternative
sent by pharmacies can only be used properly by a few experienced nurses.
Many home-healthcare patients need a reliable, easy-to-use mounting solution now.

## The Solution — IV Pole Cradle v2

An open-source cradle that any maker can print and any patient can assemble.
**v2 is the current, recommended design**: the pump seats fully and securely with
the keypad accessible, and a printed T-handle thumbscrew clamps it to a standard
home IV pole. The mounting section is the **OpenPoleMount block** — a universal
standard for any accessory on a home IV pole.

> The original **v1** is not very functional as a pump cradle and is now best
> repurposed as an accessory box that mounts below the pump.

## Files

## Quick Start

1. **Download** the STL files from [Releases](https://github.com/GoR-XarraY/openpolemount/releases/latest)
2. **Print** the v2 cradle in PLA — see the [Print Guide](https://openpolemount.com/iv-pole-v2/print-settings/)
3. **Assemble** — see the [Assembly Guide](https://openpolemount.com/iv-pole-v2/assembly/)
4. **Read the disclaimer** — [DISCLAIMER.md](DISCLAIMER.md)

No printer? You can have v2 printed on demand and shipped at cost via Slant 3D / Teleport — see [openpolemount.com](https://openpolemount.com/order/).
