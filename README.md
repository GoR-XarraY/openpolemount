**The first fully 3D-printable IV pole mounting cradle for the Curlin CMS6000 infusion pump — and the foundation for an open accessory ecosystem for home IV poles.**

> ⚠️ **REFERENCE DESIGN — NOT A MEDICAL DEVICE.** These files are provided for informational and educational purposes. See [DISCLAIMER.md](DISCLAIMER.md) before use.

---

## The Problem

Curlin CMS6000 IV pole mounting cradles are backordered. The bag alternative
sent by pharmacies can only be used properly by a few experienced nurses.
Many home-healthcare patients need a reliable, easy-to-use mounting solution now.

## The Solution

An open-source 3D-printable cradle that any maker can print and any patient
can assemble. The mounting section is designed as the **OpenPoleMount block** —
a universal standard for any accessory on a standard home IV pole.

## Files

| File | Description |
|---|---|
| `stl/OpenPoleMount_IV-Pole_v1.stl` | IV pole cradle for Curlin CMS6000 (print 1x) |
| `stl/thumbscrew_v14_flat_Thandle.stl` | Thumbscrew for pole attachment (print 1x) |
| `source/` | Editable STEP source files |

## Quick Start

1. **Download** the STL files from [Releases](https://github.com/GoR-XarraY/openpolemount/releases/latest)
2. **Print** with PETG or ASA, ≥40% infill — see the [Print Guide](https://openpolemount.com/print-settings/)
3. **Assemble** — see the [Assembly Guide](https://openpolemount.com/assembly/)
4. **Read the disclaimer** — [DISCLAIMER.md](DISCLAIMER.md)
