# No Printer? Order One

!!! note "Printing it yourself is the goal — this page is the fallback"
    OpenPoleMount is an open-source hardware project, **not a business**.
    The intended path is that you (or a maker friend) **print a cradle yourself
    for free** — see the [v3 Print Guide](iv-pole-v3/print-settings.md) (form-fitted
    pocket) or the [v2 Print Guide](iv-pole-v2/print-settings.md)
    (universal holder). This page exists so people **without access to a
    printer** aren't left out.

If you don't have a 3D printer and can't find a maker nearby, you can have the
**IV Pole Cradle v3** printed on demand and shipped to you.

## How it's printed

Orders are fulfilled through **Teleport**, the print-on-demand service from
**[Slant 3D](https://www.slant3d.com/)**. They print the exact same open-source
files published on this site — there's no special or "official" version. Parts are
printed on Slant 3D's standard Teleport profile below, which meets the
[recommended minimums](iv-pole-v3/print-settings.md) documented here.

!!! warning "This is a reference design, not a medical device"
    The printed parts you receive are the same open-source design published on this site.
    You are responsible for verifying mechanical integrity before use.
    [Read the full safety disclaimer →](safety.md)

!!! info "PETG has not been strength-tested by this project yet"
    The v3 order is printed in **PETG**. The project's load and over-tightening
    tests so far were done on **PLA** prints (see [Testing](testing.md)). Inspect
    your parts, hand-tighten only, and verify the mount holds before relying on it.
