Community-designed accessories for the OpenPoleMount block system.

    accessory on a standard home IV pole. Design your accessory to
    attach to the block and it will be compatible with all future mounts.

    **[Learn how to contribute →](../contributing.md)**

---

## The OpenPoleMount Block Standard

Any accessory that interfaces with the OpenPoleMount block can be mounted on
any compatible IV pole mount using the same thumbscrew attachment.

This means:

- **Users** only need one mount, then can swap accessories
- **Contributors** design for a known, consistent interface
- **The ecosystem** grows with every new accessory

### Dimensional Specification

Detailed mounting block dimensions will be published in v1.1 to enable
community accessories to be designed to a formal spec.

If you want to start designing now, [open an issue](https://github.com/GoR-XarraY/openpolemount/issues)
and we'll share the current dimensions.
